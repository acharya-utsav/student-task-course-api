
# Student Task and Course Management API

A backend portfolio project designed to manage
students, courses, enrollments, and academic tasks.

## Project Status

Planning and learning stage.

## Objective

Build a secure and maintainable REST API using
Python and modern backend technologies.

## Planned Technology Stack

- Python
- FastAPI
- PostgreSQL
- SQLAlchemy
- Pydantic
- Pytest
- Docker

## Learning Approach

This project is developed incrementally alongside
the learning of Python, Linux, networking,
databases, backend development, and testing.

## Features

- User registration and login
- Student and administrator roles
- Course management
- Task management
- Student enrollment
- Automated testing
